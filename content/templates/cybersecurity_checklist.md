# Cybersecurity & Compliance Checklist

**Instructions for Vendor:**
Ensure the following controls are in place before the pilot commences. This is a generic checklist applicable to all SaaS/Cloud pilots.

### 1. Data Classification & Hosting
- [ ] Data is classified according to government guidelines (Public, Restricted, Confidential).
- [ ] All data is hosted on MeitY-empanelled cloud infrastructure (if applicable).
- [ ] No data is transmitted or stored outside the sovereign borders of India.

### 2. Access Control
- [ ] Role-Based Access Control (RBAC) is implemented.
- [ ] Multi-Factor Authentication (MFA) is enforced for administrative access.
- [ ] Password policies comply with standard security benchmarks (min 12 chars, complexity enforced).

### 3. Incident Response
- [ ] A formal incident response plan is documented.
- [ ] Vendor agrees to report any suspected breach to the department within 6 hours of detection.

### 4. Audit Rights
- [ ] Vendor agrees to submit to independent security audits (e.g., CERT-In empanelled auditor) if requested.
